# WorkChat Mini 2.38.0 — Relationship Continuity

## AI Story

- Adds a short, chapter-backed relationship handoff into the private Narrative Focus for Continue Story.
- Requires a unique committed chapter, unambiguous character identity, current cast relevance and agreement with the latest relationship state; never treats a stale chapter note as current truth.
- Guides Writer to honor earned changes in trust and emotional distance without inventing drama, romance, reconciliation or mandatory plot beats.
- Tightens Continuity Repair to preserve relationship causality, language and unaffected dialogue.
- No extra Gemini API calls, stored fields, settings or UI controls.

## Reliability

- Adds in-memory regression assertions for ambiguous aliases, uncommitted chapter changes, stale relationship states, duplicated chapter numbers and scenes outside the active committed manuscript.
- Keeps current GitHub updater/release flow, Story data paths, checkpoints and the compact project root.
- Windows BUILD/Quick/Stress require GitHub Actions confirmation before updating the installed app.
