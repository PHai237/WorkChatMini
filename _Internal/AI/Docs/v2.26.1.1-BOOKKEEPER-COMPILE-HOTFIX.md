# v2.26.1.1 — Bookkeeper Compile Hotfix

Fixed `StoryMemoryBookkeeper.BuildSystemPrompt()` failing C# compilation because an interpolated raw string contained a JSON schema with literal braces.

The hotfix deliberately removes interpolation from that raw JSON prompt entirely:
- the JSON schema is stored in a normal raw string literal;
- `__PROJECT_TITLE__` and `__COMPACT_MEMORY__` are replaced after the string is created;
- JSON `{` and `}` therefore cannot be interpreted as C# interpolation syntax.

No Story Memory behavior, Story UI, provider, Discord, browser, or notification behavior changed.
