# v2.29.0 — Advanced Story Intelligence

This release builds on v2.28.6.1 and keeps the shell/browser behavior unchanged.

## Story Memory schema v4

- Canon revision ledger with provenance.
- Canon lifecycle now preserves Retconned / Contradicted facts as history instead of treating them as current truth.
- Open threads track importance plus opened/last-touched chapter provenance.
- Story arcs track priority (Core/Major/Minor) and momentum (Rising/Steady/Cooling).

## Revise Canon workflow

A new explicit `Revise Canon` Story Action proposes creator-authorized canon changes.
It returns an OLD -> NEW proposal and does not mutate memory until `Apply Revision` is pressed.
Ordinary bookkeeping is explicitly forbidden from retconning canon.

## Narrative Focus

`Continue Story` receives non-canon planning guidance generated from persistent memory:

- active arcs ranked by priority, momentum and time since last advancement;
- open threads ranked by importance and time since last touch;
- guidance to advance one primary arc at a time and avoid abrupt stale-thread resolutions;
- guidance to avoid creating duplicate mysteries/goals when an existing trajectory already covers the same function.

Narrative Focus is derived at runtime and is not itself persisted as story truth.

## Backward compatibility

Older Story Memory documents migrate to schema v4 on load/save. No synthetic retcon history is invented for older projects.
Existing arcs/threads receive safe defaults for new metadata fields.

## Verification status

Static audit is performed before packaging, but Windows WPF BUILD/AUTO-TEST is still required before claiming compile-clean or regression-clean.
