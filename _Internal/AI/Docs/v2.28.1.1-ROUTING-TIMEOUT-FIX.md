# v2.28.1.1 — Story routing + research timeout fix

- Chat is now always the lightweight direct Story chat workflow.
- Only the explicit `Draft Scene` action enters the full writing pipeline.
- Mentioning words such as `scene`, `chapter`, or `write` inside Chat no longer triggers expensive drafting stages accidentally.
- Research Gate has a 20-second fail-safe. A timeout logs a warning and continues without web research.
- Each external web research query has a 30-second fail-safe and is skipped on timeout.
- User Stop/cancellation still takes priority over these fail-safes.
- Story roles remain collaboration style only and cannot force a workflow.
