# v2.27.3 — Inline workspace redesign

This pass replaces the remaining old-style Story popup workflow with modeless in-workspace surfaces.

- Characters / Canon / Timeline / Lore / Threads now open in a right-side Story Inspector.
- AI provider/model/key, Role, Genres and Auto-bookkeeping are grouped in Project Settings in the same inspector.
- New Story is an inline editor; no setup dialog is required.
- Story list is persistent, scrollable for many projects, highlights the active project, and supports delete with destructive confirmation.
- Composer character count was removed.
- Role/dropdown contrast and selected-state visibility were strengthened.
- Selected genre chips use stronger fill + border + check mark.
- Legacy Story setup/memory/provider dialog files were removed.
- Story memory/provider/runtime behavior is otherwise unchanged.

Windows BUILD + AUTO-TEST are still required before calling the version runtime-clean.
