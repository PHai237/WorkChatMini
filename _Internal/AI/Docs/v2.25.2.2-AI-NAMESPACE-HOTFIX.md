# v2.25.2.2 — AI Namespace Hotfix

Build-only hotfix on top of v2.25.2.1.

Explicitly imports `System.IO` in AI source files that use `Path`, `File`, `Directory`, `Stream`, or `StreamReader`. HTTP providers retain explicit `System.Net.Http` imports. This avoids relying on WPF implicit-usings behavior during temporary XAML compilation. No runtime feature behavior is intentionally changed.
