# WorkChat Mini — v2.29.5-preview12

**Based on:** v2.29.5-preview11.
**Latest fully Windows-tested baseline:** v2.29.5-preview7.1 (Quick + Stress 22 PASS / 0 FAIL / 0 WARN).
**Preview12 is source-only: Windows BUILD, Quick and Stress have NOT been run.**

## Improvements

1. **Local paraphrase retrieval fallback:** When normal keyword / chapter-provenance retrieval produces no results, try a small curated set of narrative-equivalent phrases (Vietnamese, selected Vietnamese without accents, and English). The fallback never sends network or embedding requests. This is *not* broad semantic understanding.
2. **Evidence-first selection:** The chapter-index Bloom signature is only a low-cost candidate screen. Actual chapter text must contain an entire candidate phrase on word boundaries; otherwise no hit is returned. Returned excerpts explicitly carry a `Local paraphrase candidate` caveat and a real excerpt. Neither the phrase bridge nor its matches update canon or structured memory.
3. **Entity isolation:** If the Story retrieval plan already resolves a unique character identity, candidates must contain the canonical character terms. A paraphrased event cannot silently transfer to a different character.
4. **Strict precedence:** Paraphrase fallback only runs if direct indexed evidence returned no hits; ordinary explicit chapter/provenance and Continue Story recency retrieval remain unchanged. Empty-prompt Continue Story does not receive speculative semantic candidates.
5. **Whole-token direct verification:** The chapter prose scoring function no longer accepts a search word merely because it appears inside a longer lexical token. This prevents invalid direct hits from suppressing the safer fallback or being reported as evidence.
6. **Source/version fixes:** All preview12 labels synchronized. Fixes a stale `preview9` version footer that remained in the previous BUILD.bat.
7. **Expanded regression coverage:** Tests include paraphrase after zero direct hits, false-positive substrings, exact hits outranking fuzzy candidates, Vietnamese-without-diacritics query expansion, protection of named-character identity, and cache invalidation after alternate chapter changes. Still 22 top-level self-test cases.

## Constraints

- Dictionary phrases are conservative examples, not translation or embedding-based semantic search. Similar wording does **not** prove two story events are the same.
- Semantic candidates may be missed if a phrase is outside the list; direct lexical/provenance results are always preferred.
- The current fallback enumerates index entries and reads only Bloom-screened candidate chapters (maximum 24 read attempts), without keeping full manuscript contents in memory.
- No Story Memory schema v6 changes; no browser, Discord, AdBlock, API provider or UI changes. No new dependencies.
- Do not consider preview12 Windows-validated until a native build and tests are actually run.
