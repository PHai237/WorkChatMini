# v2.27.0.1 — WPF composer compile hotfix

## Fix
- Removed the invalid direct `LineHeight` property from the Story composer `TextBox` in `StoryPanel.xaml`.
- WPF `TextBox` does not expose `LineHeight` as a direct property, which caused MC3072 during the Release compile-check.
- Existing `LineHeight` usage on `TextBlock` elements is retained because it is valid there.

## Scope
- No Story Memory, provider, bookkeeping, browser, Discord, notification, or windowing behavior changed.
- Figma Archive layout and composer sizing are otherwise unchanged.

## Validation
- Static XML/XAML parse, event-handler wiring, source line-count and package integrity checks are run before packaging.
- Windows `BUILD.bat` / `AUTO-TEST.bat` remain the authority for compile/runtime PASS.
