# v2.27.2 — Story UI system pass

This pass extends the Figma Archive visual direction beyond the main Story surface.

## Main changes
- New Story is now one coherent flow: title + core genres + temporary tags in the same dialog.
- Genre selections have explicit selected states: strong border, brighter fill, and check mark.
- AI Connection is restyled as a Story Companion surface with custom dark fields/combobox, provider status, and clearer API-key state.
- Composer now exposes the current provider state directly (`Gemini/OpenAI · Ready/No key`) instead of a vague `Model` button.
- Story Memory gets the same Archive palette, clear selected tabs, stronger review actions, and a visible auto-bookkeeping toggle.
- Story dialogs request a dark Windows title bar when supported.
- No-project suggestion chips no longer render as barely-visible disabled controls.

## Logic intentionally preserved
- Story Memory persistence/retrieval/bookkeeping behavior.
- Provider API behavior and DPAPI credential storage.
- Browser, Discord Call Guard, notification policy, and performance logic.
