# v2.28.6 — Manuscript Commit + Story Arc Memory + Content Profile

## Goal

Make WorkChat Story Companion safer for exploratory writing and stronger for long-running autonomous stories:

- generated prose can be auto-committed or held as a non-canon draft;
- only committed narrative changes durable Story Memory;
- multi-scene Story Arcs are tracked separately from scene-level open threads;
- every project can define mature-theme / violence / horror / intimacy guidance without forcing one tone on every story.

## Manuscript modes

### Auto-commit narrative (default)
`Continue Story` and `Draft Scene` become committed manuscript chapters after final continuity verification. Bookkeeping reads only the final prose and stamps chapter provenance.

### Review before commit
Generated narrative remains visible in conversation but does not create a chapter, update canon, alter character state, advance arcs, or enter the Event Ledger until the creator presses **Commit to Story**.

Uncommitted narrative drafts and their paired creator instructions are excluded from later writing-pipeline conversation context so abandoned variants do not leak into future canon.

## Story Arc Memory

Memory schema is now v3 and adds `Arcs`.

An arc tracks a durable multi-scene trajectory such as:

- central mystery;
- training / progression journey;
- faction or political conflict;
- relationship arc;
- survival objective;
- long-running character goal.

Arc fields include status, stakes, progress, goals, related characters/threads, start chapter, latest chapter, and source provenance. Bookkeeping updates arcs only from final committed prose; private plans and research never become arcs by themselves.

## Content Profile

Per-project Story Settings now include:

- maturity;
- violence / gore intensity;
- horror intensity;
- intimacy boundary;
- creator notes for sensitive themes.

The profile is prompt guidance for tone and intensity. It does not override provider/platform restrictions. Mature themes, disturbing horror and graphic fictional violence can be requested when appropriate; intimacy remains bounded by the selected non-graphic profile.

## Compatibility

- Existing v1/v2 Story Memory loads into schema v3 without inventing historical arcs.
- Existing project JSON receives default manuscript/content-profile values on load.
- No browser, Discord, notification, resource-saver, icon, or root-package behavior is intentionally changed by this version.
