# v2.29.3 — Deterministic Knowledge Graph

## Goal
Improve long-story retrieval and protect structured Story Memory from clear state contradictions without adding embeddings or a database dependency.

## Knowledge Graph
The graph is derived from Story Memory at runtime. It links characters to abilities, inventory, knowledge, goals, locations, relationships, events, story/character arcs and threads. It is retrieval evidence only and is never promoted into canon by itself.

## Deterministic continuity
Structured bookkeeping deltas are checked before merge. Issues are classified as Info, Risk or Conflict. Only concrete Conflict results trigger safe suppression of structured deltas; the chapter prose can still be committed so no manuscript is lost. Risks are logged and remain available to the AI continuity stage for interpretation.

Examples of hard conflicts include reintroducing retired canon, invalid self-relationships, impossible same-time duplicate presence and a character whose current condition is explicitly dead appearing in a scene without an explicit revival event.

## Safety / compatibility
- Story Memory schema remains v5.
- No external dependency.
- Existing AI continuity passes remain active.
- Knowledge graph failure cannot delete or overwrite Story Memory.
- Browser/Discord/notification/AdBlock/resource code is outside this feature scope.
