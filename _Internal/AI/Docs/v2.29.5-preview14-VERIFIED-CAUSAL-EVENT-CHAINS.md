# WorkChat Mini v2.29.5-preview14 — Verified Causal Event Chains

**Base:** `v2.29.5-preview13`

## Main change: reliable multi-chapter causal retrieval

New `StoryCausalEvidenceTrace` provides a bounded, read-only path from a query-matched event to **explicitly linked** historical events across up to **2 hops / 6 edges**.

- Both endpoints must resolve uniquely to **Confirmed** Event Ledger records with chapter provenance.
- Supported causal relations remain CAUSES, ENABLES, BLOCKS, MOTIVATES, REVEALS, RESOLVES, ESCALATES. No relation is inferred from chronological order, shared actors, or lexical overlap.
- Direction of each link is preserved, even when traversed backward for questions like “what led to this?”.
- Duplicate IDs/summaries, missing endpoints, unsupported relation types, self-links and unconfirmed events are excluded.
- Named characters and unique aliases constrain the initial matched event. Ambiguous aliases are never auto-resolved.
- Empty or vague Continue Story prompts do not trigger chain traversal; no additional provider requests or dependencies are introduced.
- Verified chain chapter references influence retrieval ranking and appear in writer memory context under **VERIFIED CAUSAL EVENT CHAINS**, after recent chapters but ahead of lengthy chapter excerpts.
- For action-specific questions, unrelated free-form causal links are excluded from expansion and prompt context. Older generic causal recall remains for broader queries.

## Regression coverage

Extended existing `StoryLongRetrievalSelfTest` (no new top-level self-test case): 2-hop provenance across chapters, correct direction/relation, writer context, separate actor, ambiguous shared nickname, generic Continue Story, proposed event, unsupported relation, duplicate event ID.

## Compatibility and caution

- No Story Memory schema migration (remains schema v6).
- No changes to browser, Discord Call Guard, AdBlock, notification policy, AI transport, chapter storage or branch checkpoint files.
- Limits remain conservative on purpose: causal links to free-form concepts not represented as Confirmed event endpoints will **not** appear in verified chains; they remain in the existing generic causal memory view.
- **Static source checks only. Not Windows BUILD or runtime validated.** Last tested baseline: `v2.29.5-preview7.1` (Quick + Stress both 22 PASS / 0 FAIL / 0 WARN). Run integrated BUILD/Quick/Stress later as planned.
