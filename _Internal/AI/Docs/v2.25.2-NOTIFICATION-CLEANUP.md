# v2.25.2 — Notification Cleanup

- Removed unread-dot/badge UI and unread state logic.
- Messenger/Facebook/YouTube/Discord/Zalo now hard-deny Web Notification permission.
- Known service origins are persisted as Deny in the shared WebView2 profile, overriding old Allow state.
- Browser tabs continue to deny Notification permission.
- NotificationReceived remains only as defense-in-depth and always sets Handled=true.
- Removed notification-driven Smart Wake; sleeping messaging sync now uses adaptive 8/15/30-minute backoff plus user hover/click wake.
- Discord Call Guard remains unchanged and protects active WebRTC calls independently of notifications.
- Story AI Foundation remains unchanged.
