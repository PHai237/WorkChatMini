# v2.27.4 — Sidebar + Story Settings polish

- Reordered the Story sidebar to keep fixed tools above the scrollable story list, following a chat-history mental model.
- Story list entries are flat navigation rows rather than card-like buttons; clicking switches story directly.
- Fixed project-row hover rendering so hover stays inside the row bounds.
- Kept direct delete affordance on each story and preserved destructive confirmation.
- Story Settings now prioritizes genres first, then memory/bookkeeping, with AI connection at the bottom.
- Removed the duplicate Role selector from Story Settings; Role is selected only in the composer.
- Removed visible provider / memory / settings controls from the composer tool row, leaving Role plus generation status/actions.
- Provider selector now renders the provider display name instead of the implementation type name.
- No Story Memory, provider request, browser, Discord, notification, or performance behavior was intentionally changed.
