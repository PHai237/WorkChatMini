# v2.25.3 — Story UI Refresh

UI/UX-only refinement on top of v2.25.2.2, with no intended changes to provider, project persistence, Discord Call Guard, notification policy, or browser behavior.

## Main changes

- Reworked Story Companion into a compact writing-room layout.
- Removed the separate full-width genre/provider status strip.
- Added genre chips directly below the project header.
- Core genres use warm brass; temporary tags use cool blue.
- Provider/model status is now shown on the provider button itself.
- AI responses render as wider manuscript-like blocks with a subtle brass left rule.
- User prompts remain compact right-aligned bubbles.
- Assistant prose uses Cambria for long-form readability; app chrome stays Segoe UI.
- Composer is now a centered floating surface with status + Send/Stop actions.
- Empty project state includes three clickable prompt starters.
- Streaming only follows the bottom while the user remains near the bottom, so reading older text is no longer interrupted.
- New-project, genre, and provider dialogs were visually aligned with the main Story surface.
- Added `Story-UI-Design-v1.md`, including rationale and a Figma AI fallback prompt.
- Fixed version-display helper so future hotfix revision numbers are not silently truncated.

## Constraints preserved

- Native WPF only; no extra WebView.
- No shadows, blur, wallpaper, animation, or expensive visual effects.
- No source file above 1000 lines.
- Story icon remains the approved pixel open-book-and-quill artwork.
