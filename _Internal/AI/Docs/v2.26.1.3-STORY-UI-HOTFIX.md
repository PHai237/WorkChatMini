# v2.26.1.3 — Story UI / compile hotfix

Base: v2.26.1.2

## Fixes

- Fixed invalid multiline interpolated string in `StoryPanel.xaml.cs` genre tooltip construction.
- Removed the duplicate center `New story` action when there are zero projects; the project control remains the single creation entry point.
- Story status now follows the chat-first rule:
  - `Generating…` while the AI is producing output.
  - `Stopping…` immediately after Stop is requested.
  - `Bookkeeping…` during the optional memory extraction pass.
  - idle/cancelled state shows no status text.
- Stop is disabled after the first click and re-enabled on the next generation to avoid repeated cancellation input.
- No intended changes to Story Memory data structures, browser behavior, Discord Call Guard, notification blocking, or service icons.

## Validation scope

Static audit is required before distribution. Final compile/runtime validation remains `AUTO-TEST.bat` on Windows.
