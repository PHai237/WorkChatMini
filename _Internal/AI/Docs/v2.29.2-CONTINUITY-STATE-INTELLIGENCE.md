# v2.29.2 — Continuity State Intelligence

This release extends structured Story Memory from event/plot provenance into relationship, character-development and spatial continuity.

## Memory schema v5

New durable structures:

- `RelationshipHistory`: chapter-stamped transitions separate from compact current `Relationships`;
- `CharacterArcs`: internal development trajectories such as trust, grief, corruption, identity or responsibility;
- `Locations`: durable place state, explicit connections/objects and currently-present characters;
- `SceneStates`: bounded snapshots of actual generated scenes (location, time if stated, POV, cast, departures and summary).

Older projects load with empty new collections. No fake historical changes are inferred from old prose/timeline data.

## Bookkeeping rule

Only final committed prose may create these records. Private plans, research notes and discarded drafts do not mutate them. Character arcs are emitted only for durable development; scene state is explicit-only and may not place off-page characters by inference.

## Spatial consistency

When a committed scene explicitly places a character at a location, the state graph updates that character's current location and removes duplicate presence from other tracked locations. This is intentionally conservative: departure without a known destination does not invent a new location.

## Retrieval and Continue Story

Relationship transitions, character arcs and scene/location provenance participate in hybrid retrieval and chapter boosting. Continue Story receives active Character Arcs plus the latest spatial state in Narrative Focus, while current canon/revision rules remain authoritative.

## Safety / fail-open behavior

The new structures are derived structured memory, not the manuscript. Chapter Markdown remains the narrative source and the existing chapter-index fallback behavior is unchanged.
