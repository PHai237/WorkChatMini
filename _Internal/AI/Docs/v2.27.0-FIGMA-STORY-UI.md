# v2.27.0 — Figma Archive Story UI

Reference: approved `Design Workchat` Figma prototype, adapted to production WPF.

## Main surface
- Archive palette from the Figma concept: near-black surfaces, parchment text, restrained brass accent.
- Collapsible 196 px Story sidebar with New Story, current project summary, and Characters / Canon / Timeline / Lore / Threads actions.
- Sidebar memory actions open the corresponding Story Memory Inspector tab.
- Uses the existing `Assets/Icons/story.png` as Story identity and AI message avatar.
- No-project state keeps one clear New Story action.
- Empty project state has five useful task cards: Draft Scene, Plan Chapter, Build Character, Check Continuity, Expand Lore.
- Conversation uses AI-left / user-right asymmetric cards and a session divider.
- Dynamic Context strip reflects characters, canon, timeline, lore, and chapter counts.
- Composer is now a large multi-line card with quick prompt chips, Role / Model / Memory / Genres tools, character count, Stop and Send.
- Send is disabled when the composer is empty. Enter sends; Shift+Enter inserts a newline.

## Scope protection
- Story Memory storage/retrieval/bookkeeping logic is unchanged except UI count refreshes.
- Provider/orchestrator behavior is unchanged.
- Browser, Discord call guard, notification policy, windowing, and six legacy service icons are untouched.
- Figma demo-only state switcher and theme dots were intentionally not ported.

## Validation
- Static XAML parse and event-handler audit required before packaging.
- Windows BUILD/AUTO-TEST is still the authority for compile/runtime PASS.
